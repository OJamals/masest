## Traps this session paid for — add these to the 2026-09-10 list

**`route.fulfill()` bypasses CDP network throttling.** Substituting an image body from the
test process made a 48 KB and a 127 KB stand-in both score 1,708 ms — identical to within
8 ms. It produced a confident, wrong answer that I reported before catching it. Use
`route.continue({ url })` to re-point at a different REAL object. **Identical numbers across
different payload sizes means suspect the harness, not a plateau.**

**`addInitScript` accumulates per page.** Reusing one page across three samples registers
three observers summing into one counter; CLS climbed 0.0090 / 0.0181 / 0.0271 and looked
like a real regression. One page per sample.

**A templated test pin is invisible to a literal grep, and it bit twice.**
`story-six-comparisons` built its URL as `` `…/${scene}-before-aligned-202609.webp` ``, so
the filename never appears literally. Then `auth-cache-release` held `const STORY_RELEASE`
and built `` new RegExp(`story\\.js\\?v=${STORY_RELEASE}`) `` — neither `v=` nor `RELEASE`
shares a line with `story.js`. **Grep the ATTRIBUTE, not the value**, and read a test's
constant list before concluding nothing pins your target.

**`media.masest.co` is served `immutable` — overwriting an R2 object reaches nobody.**
A successful PUT still left the edge serving the old bytes (`age=387177`, TTL one year), and
the `.dev.vars` token **cannot purge** (Zone > Cache Purge is not granted). Use the site's
own `?v=` cache-bust, and move **every** reference together: `<img src>`, the
`<link rel=preload>` href (a mismatch downloads the file twice), `data-*-src`, and the
`<noscript>` fallback. Verify an overwrite with BOTH a plain and a cache-busted fetch.

**A CSS extraction that keys on `sel.startswith("@media")` silently drops every media-query
rule** whose selector is preceded by a comment. My first pass would have shipped 175 lines
instead of 322, unstyling the ledger and trust strip at max-width:720px **without failing a
single test** — no test catches a *missing* rule, only one asserting where a rule lives.
Count rules before and after any extraction.

**Proof-card narratives can never contain an apostrophe.** `seo-inject` escapes `'` as `''`
generating `supabase/seed-proof-cards.sql` while `public-document-review.test.mjs:350`
asserts `seed.includes(card.narrative)` verbatim. All 16 pre-existing cards avoid
possessives for this reason — structural, not stylistic.

**Proof-card image paths must be root-relative `/img/...`, never absolute R2 URLs.**
`tests/site-image-library.test.mjs:172` requires every snapshot path to be in
`site-images.json`'s `public_url` set (all `^/img/`). `cf-build.mjs:111` rewrites them to
the media base at deploy — which is why live `/proof` serves 27 images from R2 with zero
Supabase URLs.

**`verify.yml` gates the deploy on a sibling job, and both failure modes are silent.**
`verify:26` is `needs: [web_vitals]` and the production deploy lives *inside* `verify`.
Delete the gate job alone and the workflow is invalid — nothing runs, no red X. Leave it
orphaned and it exits non-zero, so verify is skipped and the deploy is skipped. Rename the
job and the `needs:` edge in one commit. `tests/build-architecture.test.mjs:98` also slices
the YAML on the literal job name to isolate the verify job.

**Check whether a "regression" is a timing change before assuming your edit caused it.**
`site-audit-regressions` "proof image sets" started failing because the figure gained
`class="media-fallback"` — `img/proof/cases/*.webp` live in R2, are referenced by relative
paths, and 404 locally. Removing the story made the page settle faster so the fallback
landed before the measurement. Pre-existing local-only condition, not my CSS move.

## Things that are true now and were not before

- **The CWV gate is real.** `tools/homepage-vitals.spec.mjs` runs as the `web_vitals` CI job
  and gates the deploy: LCP <= 2500 ms, CLS <= 0.01, median of 3 samples. It caught a
  0.0090 CLS regression in the new hero before it shipped. Do not let it rot.
- **`cf-build` preloads two Satoshi faces**, `satoshi-01` (body) and `satoshi-07`
  (`--heading-weight: 700`, i.e. every `.display`). The second one was the CLS fix.
- **GSAP is desktop-only.** `story.js` is gone, but the lesson stands: check whether a
  library is actually executed on the viewport that downloads it.
- **`data/story-scenes.json` survives the story** — the email campaigns depend on it. It
  carries an explicit `proofAnchor` per scene because two of the six point at proof cards
  that predate them under different slugs.

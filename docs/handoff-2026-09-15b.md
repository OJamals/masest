## Traps this session paid for

- **`git grep -E` is POSIX ERE**: `\s` and `\b` silently match nothing, so an empty result can
  be false. It hid a real miss (admin coupons lost its `Stripe` import but still built a client)
  until the guard test caught it. Scan with Node and check known positives.
- **The Stripe fetch transport captures `fetch` when a client is built.** Stub
  `globalThis.fetch` before constructing one, or the request goes to the real API.
- **Rebasing a lockfile conflict:** take the upstream lockfile, re-run the dependency install,
  and verify `package.json` kept both sides. Never hand-merge a lockfile.
- **Changing dependencies in a worktree needs its own `node_modules`**, not a symlink to the
  shared checkout.
- **zsh `for path in …` clobbers `$PATH`**; use another loop variable.
- **A push to `main` cancels an in-flight Verify** (including another agent's); check
  `gh run list` and wait.

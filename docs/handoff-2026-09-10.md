## Traps that cost real time — read before touching anything

**CMS-authoritative content.** `data/content/blog.json` is a *downstream snapshot*. The
"Refresh production CMS snapshots" step (`verify.yml:62-66`) overwrites `data/content/*.json`
from Supabase before `verify:core` builds. Anything you write there passes every local test
and every PR run, then silently reverts on deploy. Post bodies, bylines and excerpts are all
CMS-owned. Structural things (SEO titles, author entities) belong in the generator, which is
why `SEO_TITLES` and `AUTHORS` live in `tools/build-blog.mjs`.

**`build:content` is a no-op locally** — it prints `content source not configured; no
snapshots written` and skips. A "byte-identical output" check after running it proves
nothing about the Supabase path.

**Never run `npm run build` locally without `build:content` first** — it strips CMS-sourced
copy. `build:blog` and `build:comparisons` alone are safe.

**A box-shadow falls outside the element, onto the page behind it.** A dark card on a white
page still needs a light-surface shadow. This is what invalidated the `--shadow-dark-*`
change; the tokens are for shadows cast *onto* dark surfaces, and the stylesheet has only
three of those.

**`tools/surface-token-migrate.mjs` contains a false statement.** Its header claims "the
`--shadow-dark-*` tokens stay defined and are used by hand". They were never in `css/`.
That sentence misled a whole analysis pass. The rest of that file's reasoning is excellent
and worth reading.

**Phase correlation lies on before/after pairs.** Removing dirt changes image content,
producing false correlation peaks — it reported 35–228px offsets where there were none.
Use an edge-map search **plus a residual-improvement check**: if the best shift does not
reduce error, there is no shift.

**Entities inflate string length.** `&amp;` is five characters in source and one on screen.
Measuring source text is how the title finding got 42 instead of 39.

**When a test disagrees with you, read it.** `image-delivery.test.mjs:25-26` deliberately
forbids marking two homepage images eager — adding `loading="eager"` to satisfy a new guard
contradicted a real performance decision. The exemption belongs in the new test, citing the
old one.

**Green is not proof.** The reverted `--shadow-dark-*` change passed 2974/2974. No test
measures what a shadow looks like against the surface behind it.

**Measure before implementing, and measure the thing that ships.** Sixteen findings across
this branch have now turned out stale, misattributed, or backwards.

## Conventions

- `npm test`, never bare `node --test`. Never alongside Playwright — fixed ports collide.
- One blocking wait per background run. A trailing `echo` makes the task notification report
  the echo's exit code, not the suite's — read the `NPM_TEST_EXIT` line in the log.
- `git fetch && git rebase origin/main` before any push; Codex races the branch.
- Rebase conflicts: `git diff --name-only --diff-filter=U`, never a truncated `git status`.
- QA harnesses in `.qa-local/frontdoor/` (gitignored, random ports, parallel-safe).
- `css/components.css` carries no `?v=` (4h TTL); changes there propagate on that delay.

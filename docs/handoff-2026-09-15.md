## Traps this session paid for

- **`npm test` green is not `verify:core` green.** `verify:core` also runs
  `qa:workspace-regressions`, `qa:commerce-smoke` and `qa:ui-critical:interaction`
  (Playwright specs under `tools/`, which `npm test` skips). Before pushing a change to any
  page those specs cover, run the stages that touch it. A red Verify costs ~13 minutes of
  runner time and blocks deploys of everything behind it.
- **Never reuse a class for styling that a spec (or JS) locates strictly.** Adding a second
  `.checkout-payment-trust` looked like pure CSS reuse and broke a strict locator. Share the
  look with grouped selectors under a new class.
- **Specs that pin an exact list** (footer legal links, nav items) fail on intended additions.
  `git grep` the visible text of what you're changing across `tools/*.spec.mjs` first.
- **A push to `main` cancels an in-flight Verify, including a CMS-dispatch run**
  (`concurrency: verify-${{ github.ref }}`, `cancel-in-progress: true`; a dispatch run's ref
  is `refs/heads/main`). Nothing is lost — the newer run refreshes CMS snapshots too — but a
  proof run disappears. Wait for it before pushing.
- **A guard test can be redundant with another guard.** Every AK case used an Alaska ZIP, so
  the ZIP rule alone kept the test green when AK was added to the state allowlist. Only the
  mutation found it; the fix was a case with an excluded state and a contiguous ZIP.
- **`node tools/seo-inject.mjs` rewrites every sitemap `lastmod`.** Commit only the new URL.
- **zsh does not word-split `$files`**: `node --test $files` got one argument and failed with
  "Could not find". Use `bash -c`.
- **Claude-in-Chrome:** a tab opened in a fresh tab group on `masest.co/admin` stopped
  answering every script (45 s timeouts) and stayed frozen after the owner approved the
  extension prompt, while headless admin loaded normally (probe mutation-checked against a
  busy-loop page). Do not burn time retrying; ask the owner to click.
- **Background-agent claims that were wrong:** "checkout only offers UPS Ground" (the
  own-packaging filter keeps UPS and FedEx, drops carrier-packaging USPS flat rates), and
  09-14b's "`css/components.css` carries no `?v=`" (117 pages carry it). Verify before
  quoting.
